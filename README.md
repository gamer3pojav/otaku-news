# Otaku News 🗞️

**A fully automatic anime news & discovery site.** Live news, airing schedules, rankings, and a complete anime + manga library — everything updates itself.

## Features
- 📰 **Live Wire** — real anime news with photos & journalist credits, auto-refreshed
- ✍️ **The Week in Anime** — auto-curated editorial, robot-picked top stories
- 📡 **Airing Now** — live episode countdowns via AniList
- ⏳ **Upcoming** — future premieres with hype meters
- 🏆 **Power Rankings** — 4 chart modes with movement arrows (▲▼)
- 🔍 **Discover** — the entire AniList database: anime, manga, manhwa
- 🎴 **Detail pages** — exact scores, synopsis, trailers, where-to-watch, full season chains, creator credits
- 🌗 Dark/light mode · 🔍 smart search (JJK → Jujutsu Kaisen) · 120Hz-optimized

## Run locally with accounts (optional)
```
python3 server.py
# open http://localhost:8000
```
Adds login/signup + server-side news caching. The static site works fully without it.
